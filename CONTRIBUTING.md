# How to contribute

Contributions of all kinds are welcome.

 * **Suggestions, bug reports, or security issues?**\
   Open an issue on the
   [issue tracker](https://codeberg.org/ivarch/pv/issues).

 * **Translating messages to other languages?**\
   Suggest changes through
   [pv's Weblate](https://translate.codeberg.org/projects/pv/).

 * **Code changes?**\
   Fork the [repository on Codeberg](https://codeberg.org/ivarch/pv) and
   send a pull request.
   Refer to [docs/DEVELOPERS.md](./docs/DEVELOPERS.md) for coding
   conventions, and try to follow this style for commit log messages:
   [https://commit.style](https://commit.style)

If you do not speak English, please use your own language rather than using
machine translation.  Issues and pull requests generated by software agents
or written with LLM assistance will be deleted.

For more detailed information, see [docs/DEVELOPERS.md](docs/DEVELOPERS.md).

Thanks for contributing!
